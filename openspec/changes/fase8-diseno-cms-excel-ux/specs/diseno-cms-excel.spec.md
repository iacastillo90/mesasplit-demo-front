# Spec: Experiencia CMS, Exportación Excel y UI Ultra-Premium Client — MesaSplit

## Requisitos de Capacidad

### `excel-csv-export-cms-tables` (Track 1)
- MUST permitir la descarga de datos tabulares (ventas, inventario, franquicia, matriz BCG) en archivos CSV compatibles con Microsoft Excel.
- MUST incluir botones visuales de descarga ("📥 Exportar a Excel (CSV)") en el Radar Admin y Super Admin.

### `client-view-ultra-premium-ui` (Track 2)
- MUST elevar el diseño visual de la Mesa Virtual (`ClientPage.jsx`) con un header glassmorphic, banners gastronómicos promocionales y animaciones de adición al carrito.
- MUST ofrecer micro-interacciones hover elevadas en las tarjetas del menú digital.
